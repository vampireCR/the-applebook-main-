# TheAppleBook Android (Capacitor)

Android-проект TheAppleBook на Capacitor. Использует веб-файлы из `www/` и существующий Supabase backend.

## Получить APK

В репозитории GitHub откройте **Actions** → **Build TheAppleBook Android APK** → **Run workflow**. После успешной сборки скачайте artifact `TheAppleBook-Android-APK`; внутри ZIP находится `TheAppleBook-debug.apk`.

Подробная инструкция на русском: `BUILD_APK_GITHUB_RU.md`.

Параметры приложения: `com.theapplebook.app`, название `TheAppleBook`.
