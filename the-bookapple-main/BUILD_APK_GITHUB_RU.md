# Как получить APK TheAppleBook через GitHub Actions

Этот архив содержит исходный проект и workflow автоматической сборки. Сам APK появится после запуска сборки в GitHub Actions.

## 1. Загрузите файлы в репозиторий

1. Распакуйте архив.
2. Откройте папку `the-bookapple-main`.
3. Загрузите **всё её содержимое**, включая скрытую папку `.github`, в корень своего репозитория GitHub.
4. Сохраните изменения в ветку `main` (или `master`). Не удаляйте существующие файлы сайта; если GitHub спросит о замене одноимённых файлов, замените их версиями из этого проекта.

## 2. Запустите сборку

1. Откройте репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Выберите **Build TheAppleBook Android APK**.
4. Нажмите **Run workflow** → **Run workflow**.
5. Дождитесь зелёной галочки у завершившегося запуска.

Workflow также запускается автоматически при изменениях в `www/`, `package.json` или `capacitor.config.json` в ветках `main`/`master`.

## 3. Скачайте APK

1. Откройте завершённый запуск workflow.
2. Внизу страницы найдите **Artifacts**.
3. Скачайте `TheAppleBook-Android-APK`.
4. Распакуйте скачанный ZIP — внутри будет `TheAppleBook-debug.apk`.
5. Передайте APK на Android-телефон и откройте его. Android может попросить разрешить установку из этого источника.

## Важно

- Это **debug APK** для тестирования и личной установки, не подписанный релиз для Google Play.
- APK содержит локальную копию файлов из `www/`. При изменении сайта нужно обновить `www/` и собрать APK заново.
- Supabase остаётся тем же backend; аккаунты и данные не нужно переносить.
- Никогда не добавляйте Supabase `service_role` key в приложение или репозиторий.
- Если сборка упадёт, откройте лог шага с красным крестиком и пришлите его текст — по нему можно исправить причину.
